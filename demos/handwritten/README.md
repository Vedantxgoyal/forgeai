# Factory vs hand-written agent

`hr_agent.yaml` is a **starting point drafted with AI help**. For the comparison to mean "factory vs me", rewrite its
role prompt, rules and retrieval settings in your own words first. Then run:

```
forge compare runs/demo1_hr demos/handwritten/hr_agent.yaml
```

The result is written to `runs/demo1_hr/comparison.md`.
